## 📌 About The Repository

**Smart Projects** is a centralized codebase containing custom experimental scripts, rendering engines, audio pipelines, system monitor utilities, and network prototypes built from scratch using pure logic and documentation.

---

## 🚀 Key Modules & File Breakdown

### 🎨 Visual & Physics Engine (`Pygame` / Math / Graphics)
* **`Pygame_Math...` / `Vector`** — Particle emitters, black hole simulations, trigonometric vector dynamics, and polar coordinate transformations.
* **`circle.py` / `draw.py` / `kvadrat`** — Custom canvas rendering, geometry algorithms, and visual tests.
* **`rescale.py`** — Frame scaling, resolution transformations, and screen matrix manipulation.

### 🖥️ System & Hardware Automation
* **`Hardware.py` / `vm.py`** — Low-level hardware inspection, CPU/RAM telemetry, and virtual environment diagnostics.
* **`Auto Screen...`** — Dynamic screenshot capture and automated display background monitoring.
* **`Folders Sort.py` / `sorting dowlands...`** — Automated file management pipelines and sorting scripts for clean workspace organization.

### 🌐 Networking, Bots & Web APIs
* **`Server.py` / `Socket.py`** — Asynchronous TCP/UDP socket servers and client communication handlers.
* **`webhok.py` / `telegram_bot...`** — Webhook listener pipelines and custom Telegram automation bots.
* **`Bing Daily W...`** — API fetcher for daily bing wallpapers and system asset auto-updaters.

### 🎙️ Audio Pipelines & Experimental Utilities
* **`SoundDevice...` / `mic_output.w...`** — Audio stream capture, waveform processing, and microphone output management.
* **`pidagog.py` / `pisun.py` / `ScuizyBytes.py` / `play.py`** — Experimental logic, utility functions, algorithms, and sandbox testing scripts.
